# Table Maker 3

## 🎪 Generador de Tablas de Precios para Eventos

Herramienta avanzada para crear tablas de precios personalizadas para eventos y conciertos.

### ✨ Características

- 📱 **Responsive Design**: Se adapta perfectamente a desktop, tablet y mobile
- 🎨 **Personalización Completa**: Colores, tipografías, espaciado y más
- 🔧 **Estado "Agotado"**: Sistema avanzado con colores configurables y estilos dinámicos
- 📋 **Exportación HTML**: Código limpio y funcional para cualquier plataforma
- 🎯 **Dashboard Intuitivo**: Panel de control fácil de usar

### 🚀 Demo

Accede a la herramienta en vivo: [Table Maker 3](https://viernesenvenus.github.io/table-maker3/)

### 🔧 Funcionalidades Principales

#### Sistema de Estados "Agotado"
- ✅ Color personalizable para texto "Agotado"
- ✅ Línea tachada opcional
- ✅ Fondo semitransparente configurable
- ✅ Sincronización en tiempo real entre preview y código exportado
- ✅ Restauración automática al desactivar

#### Diseño Responsive
- 📱 Vista mobile optimizada
- 💻 Vista desktop con layout flexible
- 📏 Tablet view intermedia

#### Exportación Avanzada
- 📄 HTML completo con DOCTYPE y estructura
- 🎨 CSS interno con todos los estilos
- 🔧 Código auto-contenido y portable

### 💻 Uso

1. Configura tu evento (título, fecha, ubicación)
2. Personaliza los colores y estilos
3. Agrega filas y columnas según necesites
4. Configura estados "Agotado" si es necesario
5. Exporta el código HTML completo
